KODURU ARTHIKA REDDY — BIRTHDAY WEBSITE
========================================

CONTENTS
- index.html: four birthday sections
- style.css: blush-pink and cream responsive design
- script.js: navigation, optional music, letter reveal, confetti
- assets/: add your photos and optional music here

ADD 3–4 PHOTOS
Copy your photos into assets and rename them exactly:
1. arthika-1.jpg  (main portrait)
2. arthika-2.jpg
3. arthika-3.jpg
4. arthika-4.jpg

You can use only 3 photos: if you do, remove the fourth photo figure from
index.html or add a fourth photo later. JPG, PNG, or WebP formats are fine
if you update the matching filename in index.html.

OPTIONAL MUSIC
Add a music file you have permission to use as:
assets/birthday-music.mp3

PERSONALIZE
Edit the letter in index.html to include your own memories, inside jokes,
and signature.

PREVIEW
Open index.html using VS Code Live Server or another local web server.

GITHUB PAGES
1. Upload the contents of this folder to the root of your GitHub repository.
2. Open repository Settings > Pages.
3. Select Deploy from a branch, choose main and /(root), then save.
4. Wait for deployment and open the Pages URL GitHub provides.

The ZIP includes website code only; personal photos and music are not included.
